-Proyecto: tienda de discos.

-Descripción del Proyecto:
Web dinámica e interactiva enfocada en la venta de discos. Cuenta con persistencia de datos local, un flujo completo de selección y compra de productos, validación de formularios y gestión de historial de pedidos.

-Tecnologías Usadas:
HTML5:Marcado semántico (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<table>`).
CSS3:Maquetación moderna utilizando Flexbox  y CSS Grid, variables CSS (`:root`), animaciones y diseño adaptable mediante Media Queries.
JavaScript:Lógica de negocio, manipulación dinámica del DOM, validación con Expresiones Regulares y uso de localStorage para la persistencia.
Git & GitHub: Control de versiones colaborativo con uso de ramas y Pull Requests.
